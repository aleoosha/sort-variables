### Использование

- Создайте и заполните данными необходимое количество входных текстовых файлов, по умолчанию в проекте есть 2 примера тестовых файлов /input-files/in1.txt и /input-files/in2.txt 

<details>
<summary>Подробнее о входных файлах</summary>

#### Во входящих текстовых файлах построчно перечислены строковые, числовые и дробные значения
#### Примеры входного текстового файла:

###### in1.txt
```text
45
Пример
3.1415
consectetur adipiscing
-0.001
тестовое задание
100500
```

###### in2.txt
```text
Нормальная форма числа с плавающей запятой
1.528535047E-25
Long
1234567890123456789012345678901234567890.5125
```
</details>

- Запустите команду в консоли из корня проекта, например:

```bash
  java -jar ./target/sort-variables-1.0.jar -f -a -o /сохрани/сюда -p префикс-файла- /input-files/in1.txt /input-files/in2.txt
```
<details>
<summary>Подробнее о команде</summary>
  
#### Задача команды записать разные типы данных в разные файлы. По умолчанию файлы с результатами располагаются в текущей папке с именами integers.txt, floats.txt, strings.txt.

#### С помощью опции "-o" можно задать путь для результатов, относительно корня проекта, например: 
```bash
  java -jar ./target/sort-variables-1.0.jar -f -o /сохрани/сюда in1.txt in2.txt
```
#### Таким образом был задан вывод в файлы (относительно корня проекта):
###### /сохрани/сюда/integers.txt
###### /сохрани/сюда/floats.txt
###### /сохрани/сюда/strings.txt

#### Опция -p задает префикс имен выходных файлов, например:

```bash
  java -jar ./target/sort-variables-1.0.jar -f -p префикс-файла- in1.txt in2.txt
```

#### Таким образом был задан вывод в файлы (относительно корня проекта):
###### /префикс-файла-integers.txt
###### /префикс-файла-floats.txt
###### /префикс-файла-strings.txt

#### По умолчанию файлы результатов перезаписываются. С помощью опции "-a" можно задать режим добавления в существующие файлы.

#### Файлы с результатами создаются по мере необходимости. Если какого-то типа данных во входящих файлах нет, то соответствующий этому типу данных файл создан не будет.

#### В процессе фильтрации данных собирается статистика по каждому результирующему файлу. Поддерживается статистика двух видов: краткая и полная. Выбор статистики производится опциями "-s" и "-f" соответственно. Тип статистики нужно выбрать обязательно. 

#### Краткая статистика содержит только количество элементов записанных в исходящие файлы. Полная статистика для чисел дополнительно содержит минимальное и максимальное значения, сумма и среднее. Полная статистика для строк, помимо их количества, содержит также размер самой короткой строки и самой длинной.

#### Пример краткой статистики:
```text
Статистика для файла /сохрани/сюда/префикс-файла-integers.txt:

Количество элементов: 2

Статистика для файла /сохрани/сюда/префикс-файла-floats.txt:

Количество элементов: 4

Статистика для файла /сохрани/сюда/префикс-файла-strings.txt:

Количество элементов: 5
```
### Пример полной статистики
```text
Статистика для файла /сохрани/сюда/префикс-файла-integers.txt:

Количество элементов: 2
Минимальное значение: 45
Максимальное значение: 100500
Сумма всех элементов: 100545
Среднее значение элементов: 50272.5

Статистика для файла /сохрани/сюда/префикс-файла-floats.txt:

Количество элементов: 4
Минимальное значение: -0.001
Максимальное значение: 1.2345678901234568E39
Сумма всех элементов: 1.2345678901234568E39
Среднее значение элементов: 3.086419725308642E38

Статистика для файла /сохрани/сюда/префикс-файла-strings.txt:

Количество элементов: 5
Минимальная длина строки: 4
Максимальная длина строки: 42
Сумма длин всех строк: 90
Средняя длина строки: 18.0
```

<summary>Подробнее о результирующих файлах</summary>

#### В результирующих файлах построчно перечислены переменные из входных файлов, а их тип соответствует названию файла

#### Для целочисленных значений - integers.txt
#### Для дробных значений - floats.txt
#### Для строковых значений - strings.txt

#### Пример результирующих файлов:

###### integers.txt
```text
45
100500
```
###### floats.txt
```text
3.1415
-0.001
1.528535047E-25
1234567890123456789012345678901234567890.5125
```
###### strings.txt
```text
Пример
consectetur adipiscing
тестовое задание
Нормальная форма числа с плавающей запятой
Long
```
</details>
